# Zoo

Zoo 是一个面向手机现场操作的羽毛球瑞士轮与单败淘汰赛管理程序。当前版本支持 8 或 16 个参赛单位；一个参赛单位可以是一名单打球员、一组双打搭档或一支团体队。

## 完整赛制

### 8 单位模式

- 所有单位完成 3 轮标准瑞士轮，全部比赛采用 21 分一局定胜负。
- 瑞士轮只用于排种，不淘汰任何单位；8 个单位全部进入淘汰赛。
- 种子顺位依次按胜场、净胜分、直接交手结果和初始顺位决定。
- 标准三轮瑞士轮通常产生 `1×3-0`、`3×2-1`、`3×1-2`、`1×0-3` 的战绩分布。
- 四分之一决赛固定为 `1-8`、`4-5`、`2-7`、`3-6`，确保 1、2 号种子分居上下半区。

### 16 单位瑞士轮

- 16 个参赛单位，最多进行 5 轮。
- 第一轮抽签时，尽量避免同俱乐部或同小组相遇。
- 第二轮起优先在相同胜负记录内抽签，并避免重复交手。
- 达到 3 胜立即晋级八强；达到 3 负立即淘汰。
- 普通瑞士轮比赛：21 分，一局定胜负。
- 会直接决定晋级或淘汰的生死战：31 分，一局定胜负。

### 16 单位八强抽签

- 瑞士轮产生 8 个晋级单位。
- 两支 `3-0` 晋级单位必须分别对阵两支 `3-2` 晋级单位。
- 剩余三支 `3-1` 与一支 `3-2` 晋级单位自由抽签组成另外两场四分之一决赛。
- 8 单位模式不抽签，直接采用固定种子对阵。
- 四分之一决赛、半决赛和决赛均为单败淘汰。
- 淘汰赛采用每局 15 分、三局两胜。

## 现场计分

- 点击参赛单位即可选为胜者。
- 每场比赛可展开比分面板。
- 双方分数均有大号 `−`、`+` 按钮。
- 提供 `11 / 15 / 21 / 25 / 31` 快捷分数。
- 允许直接输入任意非负整数。
- 分数只用于赛事记录，不校验是否达到 15、21 或 31 分。
- 只要每场已经选择胜者，就可以结算当前轮次。
- 淘汰赛记录三局比分；未进行的第三局可保持 `0–0`。

## 手机端设计

- 录分、排名、赛程和导出使用固定底部导航。
- 当前轮结算按钮固定在拇指容易触达的位置。
- 比赛卡片与计分按钮采用大触控区域。
- 手机端排名改用卡片列表，避免横向滚动表格。
- 浏览器自动保存在本机，可导入或导出 JSON 赛事存档。

## 结果与导出

- 完赛后集中展示冠军、亚军、决赛比分、并列季军和八强名单。
- 未设置季军赛，因此两位半决赛负者明确显示为并列季军。
- 分别统计瑞士轮战绩、淘汰赛战绩和整届总战绩。
- 净胜分按每局实际比分差累计；例如 `21-16` 为 `+5`。
- 得分王从八强单位中按整届总净胜分选出；最高分并列时共同获奖。
- 可将最终名次、瑞士轮排名和完整赛果导出为一张 PNG 长图。
- 可导出带 UTF-8 编码的 CSV 结果表，支持 Excel、WPS 和手机表格软件。
- JSON 赛事数据备份独立保留，可用于恢复并继续比赛。

## 本地运行

需要 Node.js 18 或更高版本，不需要安装第三方依赖。

```bash
npm start
```

然后在浏览器打开 <http://127.0.0.1:4174>。

运行规则测试：

```bash
npm test
```

## 当前限制

- 当前仅支持 8 或 16 个参赛单位，其他人数与轮空规则尚未开放。
- 当前为本机单用户模式，没有账号与云同步。
- 没有退赛、弃权、改判和轮空流程。
- 瑞士轮同战绩时按净胜分排序；正式赛事采用前仍应将该规则写入竞赛规程。
